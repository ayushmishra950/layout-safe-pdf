# Carlito (bundled font)

`Carlito.ttc` (Regular, Italic, Bold, Bold Italic) is **Carlito** by tyPoland Lukasz Dziedzic, a font metric-compatible
with Calibri. It is used, unmodified, by the resume generator (`resume/`), which embeds a subset of it into each PDF.

Carlito is licensed under the SIL Open Font License, Version 1.1. The full license text is in [OFL.txt](OFL.txt)
and must stay next to `Carlito.ttc` whenever the font is copied or redistributed (including in the npm package).
The font is not sold on its own, and embedding it in generated documents is permitted by the license.
